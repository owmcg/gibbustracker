🚀 Get Started

Quick Start (Recommended):

  1. Install Python 3.8+ from python.org
  2. Run the setup: Double-click start_server.bat
  3. Open your browser: Go to http://localhost:5000
  4. Enjoy! Full-featured bus tracking with maps and analytics

Manual Setup:

pip install -r requirements.txt
python server.py

PowerShell Only (Current):

.\gibraltar_bus_api_final.ps1

📚 API Documentation

Available Endpoints:

GET /api/buses - All bus data
GET /api/buses/{route_id} - Specific route
GET /api/routes - Available routes
GET /api/stops/{route_id} - Route stops
GET /api/eta - Calculate arrival times
GET /api/status - System status

Data Format Example:

{
  "route_id": "2",
  "status": "active",
  "timestamp": "07/10/2025 21:48:28",
  "buses": [
    {
      "bus_id": "22a",
      "estimated_location": {"name": "Winston Churchill Ave"},
      "last_seen": "07/10/2025 21:48:28"
    }
  ]
}
